##### Arc — бренд о пути и изменениях. Название отсылает к арке персонажа — внутреннему движению, которое проходит каждый человек. Одежда здесь становится частью этой истории: отражает состояние, помогает фиксировать момент и говорит за вас там, где не нужны слова.

##### В основе бренда — лаконичный дизайн, внимание к деталям и уважение к качеству. Мы работаем в подходе slow fashion: выпускаем вещи небольшими партиями, обдуманно и только тогда, когда нам есть что сказать.
Каждая модель создана для долгой жизни в гардеробе, чтобы быть не трендом на сезон, а тихой, но значимой частью вашей личной арки.

## Установка и настройка

### Установить зависимости
```bash
npm ci
```

### Настройка файла `.env`

```bash
cp env_example.txt .env
```

Сгенерировать ```NEXTAUTH_SECRET``` можно через: ```openssl```
```bash
openssl rand -base64 32
```

### Настройка базы данных
1. В качестве БД используется PostgreSQL.
2. В ``.env`` файле по ключу ``DATABASE_URL`` нужно указать адрес подключения к БД
3. Примените миграции:
```bash
npx prisma generate
npx prisma migrate deploy
npm prisma:seed
```

Можно воспользоваться ``prisma:setup`` который объединяет в себя генерацию типов, прогона миграцию в БД, создание пользователя через seed
```bash
npm prisma:setup
```

4. Создание сиквенсов

```sql
CREATE SEQUENCE order_seq
START WITH 100000
INCREMENT BY 1;

CREATE SEQUENCE product_article_seq
START WITH 100000
INCREMENT BY 1;
```

### Настройка отправки писем по SMTP
```
EMAIL_USER=""
EMAIL_PASS=""
EMAIL_HOST="smtp.yandex.ru"
EMAIL_HOST_PORT="465"
```

В почтовом сервисе который вы используете нужно создать пароль приложения (почта) либо использовать пароль для входа (не рекомендую)
этот пароль вставить в поле ``EMAIL_PASS`` в ``.env`` файл, и сам адрес почты в поле ``EMAIL_USER``

Значения ``EMAIL_HOST`` и ``EMAIL_HOST_PORT`` нужно смотреть в документации используемого вами почтового сервиса. Выше используется
данные яндекса

### Настройка Telegram bot
```
TELEGRAM_BOT_TOKEN=""
TELEGRAM_CHAT_ID=""
TELEGRAM_WEBHOOK_SECRET=""
```
Переходим по [ссылке](https://t.me/BotFather) и создаем бота. Получаем токен. Токен вставляем в поле ``TELEGRAM_BOT_TOKEN``
Для того что бы бот уведомлял администратора о новых заказах и изменении их статуса нужно:
1. Нажать на кнопку запустить в чате с созданным нами ботом
2. После чего нам нужно отправить ``GET`` запрос подставив свой токен по адресу https://api.telegram.org/тут_токен/getUpdates
3. Переходим по вложенности result.message.chat.id - это id чата с нашим ботом. Переносим его в поле ``TELEGRAM_CHAT_ID``
4. Для того что бы покупатели могли получать информацию измененного статуса нам нужно реализовать взаимодействие через веб-хук
Создаем веб хук. Для значения ``TELEGRAM_WEBHOOK_SECRET`` генерируем сами
```bash
curl -X POST \
  "https://api.telegram.org/bot<токен>/setWebhook" \
  -d "url=https://тут_домен_сайта/api/find-order-status-telegram-bot" \
  -d "secret_token=<TELEGRAM_WEBHOOK_SECRET>"
```

### Запуск и сборка

```bash
npm run dev
```

##### После запуска приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).
##### Для сборки проекта использовать команду
```bash
npm run build
```
##### После успешной сборки для запуска приложения использовать команду
```bash
npm run start
```
